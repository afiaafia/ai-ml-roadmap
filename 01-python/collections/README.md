# Python Collections

This section covers Python's core collection data types used to store and organize groups of values.

## Topics

| File              | Topic                                  |
| ----------------- | -------------------------------------- |
| `lists.py`        | Ordered and mutable collections        |
| `tuples.py`       | Ordered and immutable collections      |
| `dictionaries.py` | Key-value data structures              |
| `sets.py`         | Unordered collections of unique values |

## Lists

Lists are ordered and mutable collections.

Key concepts:

* Creating lists
* Indexing
* Slicing
* Updating elements
* `append()`
* `insert()`
* `extend()`
* `remove()`
* `pop()`
* Sorting
* Reversing
* Iteration

## Tuples

Tuples are ordered and immutable collections.

Key concepts:

* Creating tuples
* Indexing
* Slicing
* Tuple unpacking
* `count()`
* `index()`
* Single-element tuples

## Dictionaries

Dictionaries store data as key-value pairs.

Key concepts:

* Creating dictionaries
* Accessing values
* `get()`
* Adding and updating values
* `pop()`
* `keys()`
* `values()`
* `items()`
* Dictionary iteration
* Nested dictionaries

## Sets

Sets store unique values without maintaining an index-based order.

Key concepts:

* Creating sets
* Removing duplicates
* `add()`
* `update()`
* `remove()`
* `discard()`
* Membership testing
* Union
* Intersection
* Difference
* Symmetric difference

## Learning Goals

By completing this section, I should be able to:

* Choose an appropriate collection for a given problem.
* Access and modify list elements.
* Work with immutable tuples.
* Store structured data using dictionaries.
* Remove duplicates using sets.
* Perform basic set operations.
* Iterate through Python collections.
