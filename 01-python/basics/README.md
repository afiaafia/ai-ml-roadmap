# Python Basics

This section covers the fundamental Python concepts required for working with AI and Machine Learning.

## Topics

| File              | Topic                                                       |
| ----------------- | ----------------------------------------------------------- |
| `variables.py`    | Variables, assignment, reassignment, and naming conventions |
| `data-types.py`   | Core Python data types and `type()`                         |
| `type-casting.py` | Converting values between data types                        |
| `strings.py`      | String creation, indexing, slicing, and basic operations    |
| `f-strings.py`    | Formatted string literals and value formatting              |
| `docstrings.py`   | Documenting Python modules and functions with docstrings    |

## Learning Goals

By completing this section, I should be able to:

* Create and use Python variables.
* Identify common Python data types.
* Convert values between compatible data types.
* Work with strings and access their contents.
* Format output using f-strings.
* Document Python code using docstrings.

## Practice Approach

Each file contains focused examples for the corresponding topic.

The goal is to understand the underlying concepts first and then apply them through small implementations and experiments.
